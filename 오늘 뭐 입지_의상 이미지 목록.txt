《오늘 뭐 입지?》 의상·소품 이미지 제작 목록 (스토리라인 초안 기준)

목표: 매 장면에 필요한 선택 카드 3장씩 보여 준다. 카드 위에는 이미지, 아래에는 선택 문구를 배치한다.
첫 버전 권장: 카드 그림 15장 + 공통 캐릭터 1장 + 배경 5장. 최종 캐릭터에게 모든 옷을 실시간으로 갈아입히는 기능은 후속 버전으로 둔다.

1. 개별 의상·소품 목록 (중복 없이)

[상의·겉옷: 8종]
T01 기본 반소매 상의: 처음 입고 있는 옷. 상황 1의 '겉옷 없음' 카드에도 사용.
T02 얇은 가디건: 상황 1 선택 1. 벗어서 가방에 넣을 수 있는 옷.
T03 두꺼운 점퍼: 상황 1 선택 2. 오후에는 들고 다니거나 벗어 두는 옷.
T04 그래픽 티셔츠: 상황 3 유행 스타일의 상의.
T05 선호 색 기본 상의: 상황 3 취향 스타일과 혼합 스타일에서 재사용. 선호 색에 따라 색만 변경.
T06 세로선이 강조된 얇은 겉옷: 상황 4 선택 1.
T07 밝은 색 상의 또는 겉옷: 상황 4 선택 2. 선명한 무늬 하나를 포함.
T08 부드러운 재질의 겉옷: 상황 4 선택 3. 작은 무늬 또는 무지.

[하의: 2종]
B01 와이드 데님: 상황 3 선택 1·3에서 재사용.
B02 편한 기본 하의: 시작 코디와 상황 3 선택 2. 걷기 편한 디자인.

[신발: 2종]
S01 편한 운동화: 상황 2 선택 1·3, 상황 3 유행 코디에 재사용.
S02 오래 걷기에는 다소 불편한 외출 신발: 상황 2 선택 2. 과장된 높은 굽보다 단단한 로퍼 등 중학생에게 현실적인 디자인.

[가방·소품: 4종]
A01 작은 백팩: 상황 2 선택 1, 상황 1에서 벗은 가디건을 넣는 연출에도 사용.
A02 손가방: 상황 2 선택 2.
A03 포인트 소품: 상황 2 선택 3과 상황 3 선택 3. 모자 또는 키링 중 하나로 통일하면 제작이 쉽다. 권장: 가방에 다는 색상 키링.
A04 선명한 무늬 포인트: 상황 4 선택 2의 상의와 합쳐 그리면 별도 이미지 불필요.

실제 독립 아이템 수: 15종 (상의·겉옷 8 + 하의 2 + 신발 2 + 가방·소품 3). A04는 T07에 포함.

2. 장면별 선택 카드 이미지 (각 3장, 총 15장)

상황 1 — 날씨와 겉옷
C01 가디건 단품 / 문구: “가벼운 가디건을 챙긴다” / T02
C02 두꺼운 점퍼 단품 / 문구: “두꺼운 겉옷을 입고 나간다” / T03
C03 반소매 기본 상의만 입은 모습 / 문구: “겉옷 없이 가볍게 나간다” / T01

상황 2 — 야외 탐방 준비
C04 운동화 + 작은 백팩 / 문구: “편한 운동화와 가벼운 가방을 고른다” / S01+A01
C05 단단한 로퍼 + 손가방 / 문구: “사진에 잘 나오는 신발과 가방을 고른다” / S02+A02
C06 운동화 + 색상 키링 / 문구: “운동화를 신고 좋아하는 소품으로 포인트를 준다” / S01+A03

상황 3 — 유행과 자기 취향
C07 그래픽 티셔츠 + 와이드 데님 + 운동화 / 문구: “요즘 보이는 스타일을 시도한다” / T04+B01+S01
C08 선호 색 기본 상의 + 편한 기본 하의 + 기존 신발 / 문구: “내가 좋아하는 색과 스타일로 입는다” / T05+B02
C09 선호 색 기본 상의 + 와이드 데님 + 색상 키링 / 문구: “유행하는 옷에 내 취향 한 가지를 더한다” / T05+B01+A03
※ C08·C09의 선호 색은 시작 화면 선택값을 반영. 첫 버전에서는 3~4개 고정 색 중 선택하고, 그림의 해당 영역을 CSS 색상으로 처리하거나 색별 그림을 미리 만든다.

상황 4 — 디자인 요소 비교
C10 세로선 겉옷 + 비슷한 계열의 색 / 문구: “단정하고 길어 보이는 느낌” / T06
C11 밝은 색 + 선명한 무늬 / 문구: “밝고 활기찬 느낌” / T07
C12 부드러운 재질 + 작은 무늬 / 문구: “편안하고 부드러운 느낌” / T08
※ 세 카드는 같은 캐릭터·같은 자세·같은 크기로 그려야 선·색·재질·무늬의 차이가 보인다.

상황 5 — 영상 촬영 준비 (새 옷 없음, 행동 카드)
C13 현재 옷매무새를 정돈하는 장면 / 문구: “옷매무새를 다듬고 촬영한다”
C14 가방을 내려놓고 겉옷을 정돈하는 장면 / 문구: “겉옷과 가방을 정리하고 촬영한다”
C15 키링 등 포인트 소품을 정돈하는 장면 / 문구: “내 취향을 살려 소품을 정돈한다”
※ 선택 3을 고른 학생이 키링을 갖고 있지 않더라도, 지금 착용한 옷의 색·무늬를 정돈하는 장면으로 보여 줄 수 있다.

3. 제작용 공통 규격

- 선택 카드: 세로 4:3 비율, 인물 또는 아이템 중앙 배치, 배경 단색, 카드 안에 글자 없음. 선택 문구는 웹앱에서 별도로 렌더링.
- 같은 아이템은 모든 카드에서 같은 색·모양으로 표현. 전체 그림은 밝고 친근한 일러스트 스타일로 통일.
- 특정 브랜드 로고, 실존 학교 마크, 학생 얼굴 사진 사용 없음.
- 카드 선택 전에도 옷의 재질·무늬·신발 종류가 구분되도록 표현.
- 결과 화면은 선택 기록과 현재 코디의 대표 그림을 조합한다. 모든 선택 조합(3의 5제곱=243개)에 대한 완성형 캐릭터 그림은 만들지 않는다.

4. 스토리라인 수정이 필요한 연결 부분

현재 초안의 상황 3은 체험 장소에 도착한 뒤 ‘여벌 상의와 소품으로 스타일을 바꾼다’고 되어 있지만, 선택지에는 하의 교체(와이드 데님)도 포함되어 있다. 완성본에서는 상황 3의 선택을 ‘아침에 준비해 입고 온 스타일을 확인하고 선택한 이유를 떠올리는 장면’으로 바꾸거나, 외부 체험활동 전에 학교에서 옷을 선택하는 장면으로 옮겨야 자연스럽다. 이미지 제작 전 이 연결을 먼저 확정하는 것이 좋다.
